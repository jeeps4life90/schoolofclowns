# School of Clowns Website

Upload these files to your GitHub repository.

Required files:
- index.html
- style.css
- script.js
- assets/logo.svg

After upload:
1. Go to repository Settings
2. Go to Pages
3. Source: Deploy from branch
4. Branch: main
5. Folder: /root
6. Save

Your site will publish at:
https://YOURUSERNAME.github.io/schoolofclowns/
